## Conceptos clave

Si repites el mismo pedido varias veces, conviene guardarlo. Una **skill** es una carpeta con instrucciones (y archivos de apoyo) que Claude usa cuando el tema coincide. Un **comando** propio es un atajo que invocas tú con `/nombre`.

> Skills adicionales listas para usar forman parte del Kit Premium; el contenido base es gratuito.

## Laboratorio

1. Identifica un flujo que hiciste 3 veces: por ejemplo, "crear un nuevo caso de uso con su prueba".
2. Conviértelo en una skill con pasos claros y un ejemplo de resultado esperado.
3. Crea un comando `/nuevo-caso-de-uso` y úsalo para añadir `ListarVisitas`.

## Reto

Mide cuánto tardas con y sin la skill y anota la diferencia.

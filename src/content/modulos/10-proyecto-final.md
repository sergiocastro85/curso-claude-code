## Conceptos clave

Esta semana no aprendes nada nuevo: integras todo. Lo importante no es que el código funcione, sino que puedas explicar cada parte. Si no puedes, vuelve al módulo correspondiente.

> El repositorio final comentado y el certificado forman parte del Kit Premium; el contenido base es gratuito.

## Laboratorio

1. Completa los endpoints pendientes de VisitasAPI (registrar, listar, consultar por id).
2. Ejecuta `dotnet test` hasta que todo pase.
3. Escribe un README con descripción, requisitos, cómo ejecutar y cómo probar.
4. Limpia el historial: commits pequeños y con mensajes claros.
5. Sube el repositorio a tu GitHub.

## Reto

Haz que otra persona clone tu repositorio y lo ejecute solo con tu README.

## Lista de entrega

- Repositorio público en tu GitHub.
- `dotnet build` y `dotnet test` pasan.
- README completo.
- `CLAUDE.md` y `.claude/settings.json` incluidos (sin secretos).
- Al menos un subagente, una skill y un hook configurados.
- Historial de commits legible.
